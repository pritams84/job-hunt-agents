# AGENTS.md · JobHunt AI Workspace Context

JobHunt AI is an autonomous multi-agent job application platform built with React 18, Vite, TypeScript, Express, Supabase PostgreSQL, and Stripe.

## Build Approach
**Build approach:** Tracer Bullet (end-to-end integration hardening across live APIs).  
**Workflow:** Beta (check verify, then test).

---

## Tech Stack & Commands

| Layer | Technology | Key Details |
| :--- | :--- | :--- |
| **Frontend** | React 18, Vite, TypeScript, Tailwind CSS 3.4 | Framer Motion, GSAP, Lucide icons, OLED dark theme |
| **Backend** | Express 5, Node.js (TSX) | Port 4000, Svix Clerk Webhooks, Stripe Webhooks |
| **Database** | Supabase PostgreSQL | 7 tables, Row-Level Security, pgvector HNSW cosine ops |
| **Testing** | Vitest 1.6.1 | `pnpm test` (or `npx vitest run`) |
| **AI Engine** | OpenAI SDK + NVIDIA Nemotron 70B | JSON repair self-healing prompt pipeline |

### Standard Development Commands
- `pnpm dev`: Start Vite development server (Port 5173).
- `pnpm server`: Start Express backend server (Port 4000).
- `pnpm dev:all`: Launch both frontend and backend concurrently.
- `pnpm test`: Execute Vitest automated unit/integration test suite.
- `pnpm typecheck`: Validate TypeScript compilation (`tsc --noEmit`).
- `pnpm build`: Build production bundle (`tsc && vite build`).

```
├── server/

│   └── supabase.ts        # Supabase Admin client with service role key

│   └── pages/             # 11 React page views
└── test-preferences.json  # Configured test runner preferences (Vitest)
```

## Installed Agent Skills

- `karpathy-guidelines`: Principles to avoid overcomplication and enforce surgical changes.
- `scope`: Living project roadmap and slice planning in `docs/scope/`.
- `architect`: Technical specifications and architectural decisions in `docs/specs/`.
- `develop`: Feature implementation to specification.
- `check`: Runtime verification (`verify`) and fresh-model code reviews (`review`).
- `test`: Automated test suite authoring (`vitest`).
- `sync`: Durable context and documentation maintenance.
- `document`: Release notes and PR drafting.
- `audit`: Codebase context bootstrapping.
